# Body Beast: Build Chest/Tris

Interactive workout app for the Body Beast **Build: Chest/Tris** routine — 37 sets across 6 blocks, with AI-generated exercise demo videos.

**Live:** `https://tyronetse.github.io/BuildChestTris/` (enable GitHub Pages: Settings → Pages → Deploy from branch → `main`)

## Workout structure

| Block | Type | Exercises |
|-------|------|-----------|
| 1 | Single Set | Dumbbell Chest Press · 15-12-8-8 |
| 2 | Super Set | Incline Dumbbell Fly ⇄ Incline Dumbbell Press · 15/15, 12/12, 8/8 + drop |
| 3 | Giant Set | Close Grip Press / Partial Chest Fly / Decline Push-Up · 15s, 12s, 8s |
| 4 | Single Set | Triceps Extension · 15-12-8-8 |
| 5 | Super Set | Single Arm Kickback ⇄ Triceps Push-Up |
| 6 | Super Set · 60s | Dips on Bench ⇄ Ins and Outs |

## Features

- Same design as the [BodyBeastTotalBody](https://github.com/tyronetse/BodyBeastTotalBody) app
- Sticky now-playing demo video, tap any set to jump to it
- Start / Pause / Resume, set progress, elapsed timer
- 30/45/60/90-second set and rest timers, rest auto-advance
- Loud 4-beep timer alert, screen wake lock
- Per-exercise weight logging with last-used memory
- Muted demo videos so phone music keeps playing
